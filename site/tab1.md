# 菜谱 App 设计规范文档

> 生成时间：2026-07-04
> 用途：供 AI 代码助手（Claude Code + DeepSeek）理解并还原设计

---

## 一、整体风格定义

| 维度 | 规范 |
|------|------|
| 设计语言 | iOS 原生风格，干净、轻量、高留白 |
| 视觉基调 | 温馨生活感，以白色为底、蓝色为品牌色、食物图片为视觉焦点 |
| 圆角体系 | 全局大圆角：卡片/按钮 16-20px，图片 12-16px，小标签 20px（pill 形） |
| 阴影 | 极浅或无阴影，靠背景色分层（浅灰 vs 纯白） |
| 图标风格 | 线性图标（2px 描边），圆角端点，无填充 |

## 二、色彩系统（Design Tokens）

```
Background Primary:   #FFFFFF  (页面底层背景)
Background Secondary: #F2F2F7  (卡片容器、分组背景、搜索框背景)
Background Tertiary:  #E5E5EA  (分割线、极细边框)

Brand Primary:        #007AFF  (主按钮、选中态、链接文字、复选框)
Brand Primary Light:  #E3F2FD  (次要按钮背景、轻量高亮底色)
Brand Primary Hover:  #0051D5  (主按钮按下态)

Accent Orange:        #FF6B35  (温度数值高亮：350°F / 175°C)
Accent Red:           #FF3B30  (删除按钮、删除图标、时间高亮)
Accent Green:         #34C759  (Start 按钮、成功态)

Text Primary:         #000000  (标题、正文)
Text Secondary:       #8E8E93  (占位符、次要信息、禁用态)
Text Tertiary:        #C7C7CC  (分割线、极弱提示)

Tag Background:       #E3F2FD  (标签 pill 背景)
Tag Text:             #007AFF  (标签 pill 文字)
```

## 三、字体层级（Typography）

| 层级 | 用途 | 字号 | 字重 | 颜色 |
|------|------|------|------|------|
| Display | 页面大标题（All Recipes） | 34px | Bold (700) | Text Primary |
| Title 1 | 菜谱名称（详情页顶部） | 28px | Bold (700) | #FFFFFF（叠在图片上）或 Text Primary |
| Title 2 | 卡片标题、板块标题（Ingredients / Method） | 20px | Semibold (600) | Text Primary |
| Body | 正文、步骤描述 | 17px | Regular (400) | Text Primary |
| Body Emphasis | 食材数量（1 cup / 1 tsp） | 17px | Semibold (600) | Brand Primary |
| Callout | 标签文字（12 servings / 10 min） | 15px | Medium (500) | Text Secondary |
| Caption | 底部导航文字、占位符 | 12px | Medium (500) | Text Secondary |
| Nav Active | 底部导航选中项 | 12px | Semibold (600) | Brand Primary |

## 四、页面 1：All Recipes（菜谱列表页）

### 4.1 顶部导航栏

```
+-------------------------------------+
|  <-  All Recipes              ...   |  左：返回箭头（线性，无文字） 右：更多按钮（三个点）
|                                     |
|  [Q]  Recipes, Ingredients and More |  搜索框：圆角 pill（24px），浅灰底，左侧放大镜图标，占位符灰色
|                                     |
+-------------------------------------+
```

- **搜索框**：高度 44px，背景 Background Secondary，圆角 12px，内边距 12px 16px
- **更多按钮（...）点击展开**：底部弹出的 Action Sheet
  - Sort by Name（按名称排序）
  - Sort by Cook Time（按制作时间排序）
  - Select Recipes（多选模式，进入批量操作）

### 4.2 菜谱列表（List 模式）

```
+-------------------------------------+
|  +----+  Chocolate Chip Cookies     |
|  |    |  +--------+--------+        |
|  | 图 |  | [👥] 12  | [⏱] 10min|   |  缩略图 80x80px，圆角 12px
|  | 片 |  +--------+--------+        |  标签 pill：背景 #F2F2F7，圆角 20px，图标+文字
|  +----+                             |
|  ---------------------------------  |  分割线：1px，Background Tertiary
|  +----+  Chocolate Chip Cookies     |
|  |    |  +--------+--------+        |
|  | 图 |  | [👥] 12  | [⏱] 10min|   |
|  | 片 |  +--------+--------+        |
|  +----+                             |
|  ---------------------------------  |
|  ...                                |
+-------------------------------------+
```

- **列表项**：左图右文布局，图片 80x80px，右侧文字垂直居中
- **信息标签**：pill 形状，图标（👥 人数 / ⏱ 时间）+ 数值，背景浅灰，内边距 4px 10px
- **分割线**：全宽 1px，左右缩进 16px（或图片右侧对齐）

### 4.3 底部导航栏（Tab Bar）

```
+-------------------------------------+
|  [📅]    [📋]    [🛒]    [👓]    [⚙️]  |
| Meal Plan Recipes Groceries Discover Settings
|         ^ 选中态：图标填充蓝色，文字蓝色
+-------------------------------------+
```

- **高度**：83px（含安全区），背景白色，顶部 1px 分割线
- **图标**：24x24px，线性风格，2px 描边
- **选中态**：图标 + 文字变为 Brand Primary，图标下方有轻微背景高亮（圆形浅蓝底）
- **未选中态**：图标 + 文字为 Text Secondary

### 4.4 悬浮按钮（FAB）

```
        +-----+
        |  +  |  右下角，圆形，直径 56px
        +-----+     背景 Brand Primary，白色加号图标
```

- 位置：右下角，距边缘 16px，底部导航上方 16px
- 点击：进入新建菜谱流程

## 五、页面 2：Recipe Detail（菜谱详情页 — 只读模式）

### 5.1 顶部区域（Hero Section）

```
+-------------------------------------+
|  <-  ...                            |  左上返回，右上更多按钮
|                                     |
|  +-----------------------------+    |
|  |                             |    |
|  |    [食物大图，全宽，圆角]    |    |  16:9 或 4:3 比例，圆角 16px
|  |    Chocolate Chip Cookies   |    |  图片底部叠加渐变遮罩 + 白色标题
|  |                             |    |
|  +-----------------------------+    |
|                                     |
|  +----------+  +----+  +----+       |
|  | ▶ Start  |  | 🛒 |  | ⬆️ |       |  Start 按钮（绿色大按钮）+ 购物篮 + 分享
|  +----------+  +----+  +----+       |
|                                     |
|  +--------+  +----------------+     |
|  | [👥] 12  |  | [⏱] Prep 10 min  |   信息卡片，浅灰底，圆角 12px
|  +--------+  +----------------+     |
|                                     |
+-------------------------------------+
```

**Start 按钮规范：**
- 尺寸：宽自适应，高 48px，圆角 24px（pill 形）
- 背景：Accent Green（#34C759）
- 文字：白色，17px Semibold，左侧播放三角形图标
- 点击：跳转至 Meal Plan Tab（Tab 2）

**操作按钮（购物篮 / 分享）：**
- 尺寸：48x48px，圆形，浅灰底（Background Secondary）
- 图标：24px，线性，Brand Primary 或深色

### 5.2 Ingredients 板块

```
Ingredients                    [Scale] [⚙️]  标题左对齐，右侧 Scale 按钮 + 筛选图标

+-------------------------------------+
|  1 cup unsalted butter, softened    |  数量"1 cup"蓝色高亮，其余黑色
|  1 tsp baking soda                  |
|  ½ tsp salt                         |
|  ...                                |
+-------------------------------------+
```

- **板块标题**：Title 2 样式，左侧对齐
- **Scale 按钮**：pill 形状，浅蓝底，Brand Primary 文字，点击可调分量
- **食材项**：数量部分（数字 + 单位）用 Brand Primary 色，食材名称用 Text Primary

### 5.3 Method 板块

```
Method

+-------------------------------------+
|  +--+  Preheat your oven to         |
|  |1 |  350°F (175°C). Line a        |  左侧蓝色圆圈数字
|  +--+  baking sheet with...         |     温度用橙红色高亮
|                                      |     食材名用蓝色高亮（可点击）
+-------------------------------------+

+-------------------------------------+
|  +--+  Bake for 10-12 minutes,      |
|  |2 |  or until the edges...        |  时间用红色高亮（可点击唤起计时器）
|  +--+                               |
+-------------------------------------+
```

**步骤卡片规范：**
- 背景：白色，圆角 16px，内边距 16px
- 步骤编号：32x32px 蓝色圆形，白色数字，居中
- 文字：Body 样式，温度橙红、食材蓝色、时间红色
- **可点击高亮**：
  - 蓝色食材 → 弹出 tooltip 显示数量（如 "1 cup sugar"）
  - 红色时间 → 唤起系统计时器，同步至灵动岛 / 锁屏实时活动

### 5.4 Tags 板块

```
Tags
+---------+

+---------+

Shared by Crouton ❤️  底部居中，灰色小字 + 粉色爱心
```

### 5.5 更多菜单（...）

点击右上角 ... 弹出 Action Sheet：
- Edit Recipe（编辑菜谱）

- Delete Recipe（删除，红色警示文字）

## 九、交互动效规范

- **页面转场**：iOS 标准滑动转场，从右向左推入
- **按钮点击**：0.15s 缩放至 0.96，松手回弹
- **列表项拖拽排序**：长按触发，上浮阴影，拖拽时半透明
- **弹出层**：从底部滑入（Sheet），背景遮罩黑色 30% 透明度
- **高亮文字点击**：轻微缩放 + 底部 tooltip 滑入
- **计时器唤起**：系统级动画，无缝同步至灵动岛
