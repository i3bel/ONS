# 菜谱 App 设计修改意见 — 趋近设计稿

> 生成时间：2026-07-04
> 基于：用户提供的 5 张设计稿截图 vs 当前实现效果对比

---

## 一、全局色彩系统修正

当前实现偏离设计稿，需统一调整：

| Token | 设计稿值 | 当前问题 | 修正方向 |
|-------|---------|---------|---------|
| **页面背景色** | `#F2F2F7` (iOS 系统灰) | 可能偏白或偏深 | 统一使用 iOS 系统灰 `#F2F2F7`，所有页面底层必须为此色 |
| **卡片背景色** | `#FFFFFF` 纯白 | — | 保持纯白，与页面背景形成层级 |
| **品牌蓝** | `#007AFF` (iOS 系统蓝) | 可能偏深或偏浅 | 严格使用 iOS 系统蓝，禁止自定义近似色 |
| **绿色按钮** | `#34C759` (iOS 系统绿) | — | Start 按钮必须使用此色 |
| **红色删除** | `#FF3B30` (iOS 系统红) | — | 删除图标、减号按钮使用此色 |
| **文字主色** | `#000000` | — | 标题、正文纯黑 |
| **文字次要色** | `#8E8E93` | — | 占位符、次要信息 |
| **分割线** | `#E5E5EA` | 可能过粗或过深 | 1px 细线，颜色必须浅 |

**关键修正：** 所有页面底层背景必须是 `#F2F2F7`，白色仅用于卡片/输入框/按钮等前景元素。当前实现若页面底层为白色，需立即修正。

## 二、页面 1：All Recipes（菜谱列表页）

- 标题 "All Recipes" 可能字号偏小或字重不够
- 右上角 "..." 按钮可能样式不对

设计稿规范：
+-------------------------------------+
|  09:30                    信号 电池  |  <- 状态栏标准 iOS
|                                     |
|  [···]  All Recipes           [...] |  <- 左：返回/菜单  右：更多按钮
|                                     |

- **标题 "All Recipes"**：字号 34px，字重 Bold，纯黑，左对齐（不是居中！）
- **右上角 "..." 按钮**：白色圆形底，黑色三个点，直径约 36px，不是纯文字
- **搜索框**：圆角 pill 形，高度约 40px，背景 `#E5E5EA` 或 `#F2F2F7`，左侧放大镜图标，占位符灰色

### 2.2 菜谱列表项

```
设计稿规范：
+-------------------------------------+
|                                     |
|  +----+  蛋炒饭                     |
|  |    |  +--------+  +--------+     |
|  | 图 |  | 👥 1   |  | ⏱ 29min|    |  <- 缩略图 80x80px，圆角 12px

+-------------------------------------+
```

**关键修正：**
- **缩略图**：80×80px，圆角 12px，不是正方形直角
- **无图片占位**：浅蓝底 `#E3F2FD`，中央蓝色餐具图标（🍴），不是灰色或文字占位
- **标签 pill**：背景 `#F2F2F7`（比卡片背景稍深），圆角 20px（大圆角），内边距 6px 12px，图标+文字同行
- **分割线**：1px `#E5E5EA`，贯穿或左右缩进 16px
- **列表项间距**：项与项之间无额外间距，靠分割线分隔，或每项有微小圆角白色卡片感

### 2.3 底部导航栏（Tab Bar）

```
设计稿规范（3 Tab 版本）：
+-------------------------------------+
|  [📖]      [🍳]      [🛒]          |
|  食谱       烹饪        采购          |
|    ^ 选中态：图标填充蓝色，文字蓝色，有浅蓝圆角背景
+-------------------------------------+
```

**关键修正：**
- **选中态**：图标变为填充蓝色（不是线性描边），文字蓝色，图标外有浅蓝圆角矩形背景 `#E3F2FD`，圆角约 12px
- **未选中态**：图标线性描边，灰色，文字灰色
- **Tab 数量**：设计稿是 3 个（食谱/烹饪/采购），不是 5 个
- **高度**：标准 iOS Tab Bar 高度，含安全区

### 2.4 悬浮按钮（FAB）

```
设计稿规范：
        +-----+
        |  +  |  <- 右下角，圆形，直径 56px
        +-----+     背景 `#007AFF` 品牌蓝，白色加号，有轻微阴影
```

- 位置：右下角，距边缘 16px，底部导航上方
- 阴影：轻微投影，y 偏移 2px，模糊 8px，透明度 15%

## 七、关键差异总结（当前实现 vs 设计稿）

| # | 差异点 | 设计稿 | 当前实现需修正 |
|---|--------|--------|---------------|
| 1 | 页面背景色 | `#F2F2F7` 系统灰 | 检查是否为白色，需修正 |
| 2 | 列表项样式 | 白色卡片/平铺+分割线 | 检查是否过度使用阴影或圆角 |
| 3 | 底部导航 | 3 Tab，选中有浅蓝背景 | 检查是否为 5 Tab，选中态是否正确 |
| 4 | Hero 图片 | 全宽大图+社交按钮叠加 | 检查是否有社交按钮，标题是否正确叠加 |
| 5 | Ingredients 布局 | 左名右数量，平铺列表 | 检查是否为卡片式或数量位置不对 |
| 6 | 复选框形状 | 圆形 | 检查是否为方形，需修正为圆形 |
| 7 | 步进器样式 | 灰色圆按钮 [−] [值] [+] | 检查样式是否匹配 |
| 8 | 标签 pill | 浅蓝底蓝字，带 # | 检查颜色、圆角、前缀 |
| 9 | 按钮圆角 | 大圆角 pill（24px+） | 检查是否圆角过小 |
| 10 | 字体层级 | 严格区分 Display/Title/Body | 检查字号、字重是否匹配 |

## 八、实现优先级建议

1. **P0（必须）**：修正页面背景色、品牌蓝颜色值、按钮圆角为 pill 形
2. **P1（重要）**：修正列表项布局（左图右文/左名右数量）、底部导航 3 Tab 样式、复选框圆形
3. **P2（优化）**：Hero 区域社交按钮、食材高亮交互、标签样式、步进器样式
